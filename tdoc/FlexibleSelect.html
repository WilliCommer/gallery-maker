Class: FlexibleSelect

FlexibleSelect()

Implements a HTMLElement that works like a <select multiple > but use <div> instead of <option> Therefore, it allows for arbitrary options that can also include images. It self ist styled like a Bootstrap form-control.
It is defined as Custom Element <flexible-select> in this module and supports attributes "name", "multiple" and "tabindex". It also supports "value" and "form" and the events "change" and "input". If "multiple" the "value" is an array else a string.
The childen supports attributes "selected" and "value"
