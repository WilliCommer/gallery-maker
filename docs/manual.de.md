## Galery Maker Handbuch

Mit diesem Programm werden Fotogalerien fürs Web erstellt. Es können mehrere Projekte erstellt werden. 
Jedes Projekt ist eine Fotogalerie und wird in einer Datei gespeichert (Endung ".gmp"). 
Der Zugriff erfolgt klassisch im Hauptmenü "Datei":
- Neu (Neues Projekt anlegen)
- Öffnen (Vorhandene Detei öffnen)
- Zuletzt benutzt
- Speichen  
- Speichern unter

Der Punkt "Speichern" ist eher unnötig, da Änderungen automatisch gespeichert werden. Das Schließen des Browsertab beendet auch den Hintergrundservice. Da aber immer gespeichet wird erscheint bei einem Neustart der App der alte Zustand.

Im Menü kann zwischen den Ansichten Projekt, Bilder und Galerie gewechselt werden.

### Projekt

Hier wir der Titel der der Galerie-Seite und der Name der HTML-Datei angegeben (Standard ohne Name ist "index")

Dann kann das Zielverzeichnis gewählt werden wo die Galerie abgelegt wird. Der aktuelle Projektdateiname wird angezeigt.

### Bilder

Hier werden die Bilder der Galerie als Liste angezeigt. Die Reihenfolge kann geändert werden und Bilder können gedreht werden.

Jedes Bild bekommt eine Beschriftung und eine optionale längere Beschreibung.

Über den Menüpunkt "Bilder hinzufügen" werden Bilder in die Liste aufgenommen.

Um das reine Sortieren übersichtlicher zu machen gibt es im Menü die Option der Kompaktansicht.

### Galerie

Wenn die Galerie gewählt wird erzeugt die App sofort die fertige Galerie und zeigt eine Vorschau.

Die Galerie besteht aus einer einzelnen HTML-Datei die ohne CSS, JavaScript oder anderen externen Resourcen auskommt. Lediglich die Fotos liegen als Kopie in einem Ordner, deshalb können HTML und Ordner einfach im Web veröffentlich werden oder auf dem eigenen Computer auch ohne die App genossen werden.
